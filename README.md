# 刷题工具

把考试真题 PDF 一键转成**在线刷题页面**：自动解析选择题、即时判分、错题带解析、支持多用户账号。

> 用户上传自己的真题 PDF（文字版），工具自动提取题目和选项，生成可刷、可判分、可反复练习的题库。

## 功能特性

- 📄 **真题转题**：上传文字版 PDF / docx，或直接粘贴文字，自动解析「题目 + ABCD 选项 + 答案 + 解析」
- 🎯 **即时判分**：点一下选项，立刻显示对错和正确答案
- 📚 **科目分类**：按「科目 → 年份/批次」自动归档
- 🔀 **汇总刷题**：把某科目所有题合并、打乱顺序，反复练习
- 👤 **多用户**：注册/登录，每人独立题库，互不可见
- 📱 **移动端友好**：手机/电脑浏览器都能用

## 快速开始

### 方式一：Docker（推荐）

```bash
docker compose up -d --build
```

然后打开 `http://localhost:8000`。

### 方式二：本地运行

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## 支持的文件格式

| 输入 | 支持 |
|---|---|
| 文字版 PDF（docx 导出 / 网上整理的） | ✅ |
| .docx / .doc 文件 | ✅ |
| 直接粘贴文字 | ✅ |
| 扫描件 / 拍照 PDF | ❌ 暂不支持（需 OCR） |

## 技术栈

- 后端：FastAPI + SQLite（无需外部数据库）
- 前端：原生 HTML / CSS / JavaScript（无框架）
- 解析：pypdf（PDF 文字提取）+ 正则解析器

## 目录结构

```
quiz-app/
├── main.py          # FastAPI 入口 + 路由
├── auth.py          # 用户认证（SQLite）
├── services/
│   ├── parser.py    # 真题解析核心
│   └── quiz_template.html
├── static/          # 前端页面
├── data/            # 题库数据（运行时生成，不提交）
├── Dockerfile
└── docker-compose.yml
```
